抖音 + 快手 · 手游入驻与发行流程手册

覆盖抖音原生手游与快手 Android 联运的注册、接入、审核、上线和退服流程

1. 账号、主体与认证

抖音 原生手游厂商入驻

主入口：game.open.douyin.com。本手册的抖音主流程为游戏厂商合作平台，不使用通用开放平台的小游戏、小程序或小玩法主体规则。

材料执行要求
企业营业执照主体名称、统一社会信用代码及有效期与后台填写一致
法定代表人身份证件按后台要求提交正反面及身份信息
入驻申请函使用平台模板并按要求签章
增值电信业务经营许可证（ICP）抖音游戏平台现行操作指南列为入驻必备材料

主体管理：统一社会信用代码和主体类型不支持直接变更；正式提交前应确认运营主体、软著主体、版号运营单位及授权链的一致性。

快手 Android 游戏联运入驻

通过快手游戏生态合作平台完成管理员账号认证、协议签署、游戏资料和结算信息管理。管理员账号代表开发者办理入驻、协议、费用结算、达人和数据管理等事项；具体准入材料及商务流程以游戏生态合作平台当前页面和已签协议为准。

2. 游戏创建与包型选择

抖音 创建或认领原生游戏

主体审核通过后进入 game.open.douyin.com。如系统识别到历史合作游戏，可认领并复用已有资料；认领用于减少重复填写，不代表审核提速。

包型决策

合作场景包型与配置执行要点
游戏资料分发、开放 SDK、发行人计划等官方包按游戏创建页和具体增值服务要求配置，不接入未申请的联运能力
普通联运联运包，SDK 中 union_mode=0完成登录、支付、服务端验签和渠道包验收
直播联运联运包，SDK 中 union_mode=1先申请合作并签署协议，再完成 SDK 接入和联运包上传

填写游戏资料

填写名称、开发商、分类、简介、隐私政策和安装包信息；开发商按软著著作权人填写，主体不一致时补齐授权链。

配置状态和分发信息

Android 状态包括暂未上架、开始下载和开放下载；按实际发行节点申请开放预约，配置监测链接和 schema 地址。

提交平台资质字段

上传软著、版号及代理授权材料。现行直播联运指南对不含内购的产品提供承诺书并将证书编号填“0”的提交路径；该路径只代表平台材料受理方式，不构成出版审批豁免。

提交审核

抖音游戏平台现行指南称提交游戏资料后将在 3 个工作日内通知审核结果；驳回后按反馈补件并重新提审。

快手 创建 Android 联运游戏

确认合作方案

在游戏生态合作平台或与对接人员确认分发、联运、结算和内容经营范围，完成协议及主体信息。

获取接入参数

取得游戏 AppID、当前版本 SDK、参考 Demo 和必接美术资源；Android 包名须以 .kuaishou 结尾。接入支付时生成 RSA 4096-bit 密钥对，并向快手提交开发者支付公钥。

制作并验收渠道包

接入联运 SDK、快手闪屏和角标，完成登录、实名、防沉迷、支付及隐私合规自测后提交平台验收。

发布与持续维护

按合作后台和书面排期发布；母包更新时同步制作、验收并维护最新联运包。

4. 技术接入与验收清单

抖音 官方包与联运包

验收域官方包普通 / 直播联运包
身份参数核对游戏 ID、开放平台应用、包名、签名和已申请权限核对 app_id、app_secret、包名、签名；普通联运 union_mode=0，直播联运 union_mode=1
版本安装包版本号、VersionCode、下载地址和页面展示版本一致VersionCode 和 VersionName 均不为空；母包、渠道包和服务端版本配置一致
登录仅验收已申请的开放能力，不默认接入联运账号体系客户端取得 token 后由游戏服务端完成校验并取得游戏用户标识；覆盖登录、切换账号、退出和异常重试
支付与验签无联运支付时按官服支付链路验收校验订单金额、商品、订单号、签名和服务端回调；回调必须幂等，并以服务端结果入账
隐私与权限隐私政策主体、SDK 清单、权限用途和实际行为一致；按当前 SDK 文档完成初始化时机与权限自测
分发回归验证 schema、监测链接、下载/安装/更新、弱网、崩溃、账号和支付异常；保留自测记录与可回滚包

直播联运排期：官方流程为申请接入、签署协议、接入 Android 联运 SDK、上传联运包，并未要求等官服正式上线后才开始。计划在首发启用时，应在公测前完成申请、合同、技术接入和包体验收。

快手 Android 联运包

  • 从官方 SDK 下载页获取当前最新版基础版或拓展版，使用最新版 AAR 和参考 Demo。
  • 基础版验收登录、实名认证、防沉迷、支付、悬浮球/用户中心和数据上报；需要游戏内视频分享时使用拓展版。
  • 核对 AppID、Android 包名、签名、版本号和渠道配置；包名须以 .kuaishou 结尾，母包加入官方闪屏和角标资源。
  • 在快手后台开启实名认证和防沉迷后，验证 SDK 登录时的实名弹窗、未成年人时段限制和异常账号处理。
  • 支付签名使用 RSA 4096-bit 密钥，签名及验签算法为 SHA512WithRSA；签名时排除 null 和空字符串字段，并按字段名升序拼接。
  • 下单由游戏服务端使用开发者私钥签名，快手使用开发者提交的公钥验签；支付回调由游戏服务端使用快手提供的中台支付公钥验签。验签通过且服务端确认成功后再发货。
  • 支付验收覆盖重复通知、退款、掉单、金额篡改和订单幂等；客户端支付完成回调不作为支付成功的唯一依据。
  • 按最新隐私说明核对 SDK 采集字段、三方 SDK、权限申请和用户同意前后的初始化行为。

5. 预约、测试与发布

抖音 原生手游

创建详情页并提交资料

完成游戏资料、物料、隐私政策和资质字段，选择与合作方案一致的包型并提交审核。

按节点申请预约或下载

在版本管理中申请开放预约、更新游戏资料或开放下载；预约、预下载、测试活动和首发资源是否开放，以后台当前能力及书面运营方案为准。

完成测试与联运验收

官方包按申请能力测试；普通/直播联运包完成客户端、服务端和支付验收。计划首发启用直播联运时，不得把 SDK 接入推迟到正式上线后。

上线与版本维护

确认页面状态、下载包、开服时间、监测和回滚包后发布；后续在版本管理中更新资料和包体，联运包跟随官服版本维护。

快手 Android 联运

测试资格、渠道包验收、开放下载和首发排期按游戏生态合作平台当前流程及合作协议执行。公开文档未给出适用于所有项目的统一审核 SLA，不将内部缓冲时间写成平台承诺。

发布门禁：发行、研发、QA、法务和财务应共同确认“资质通过、包体一致、登录支付通过、隐私合规、监测可用、公告就绪、回滚可执行”后再发布。

7. 商业化、分成与结算

抖音 原生手游

公开接入指南未给出适用于所有游戏的统一分成比例，收入分配以具体合作协议为准。

  • 直播 / 普通联运：渠道、平台、主播或其他参与方的比例按签署协议执行

9. 版本更新、暂停服务与退服

产品线版本更新 / 回滚暂停与终止运营
抖音原生手游在版本管理中更新游戏资料和包体；联运包与官服版本同步，发布前保留上一稳定包和配置按平台后台、合作协议和用户权益要求完成公告、关闭新增与支付、资产处理、下架申请和结算收尾
快手 Android 联运更新母包时同步生成并验收快手渠道包，核对 SDK、版本号、支付和隐私变化游戏生态合作平台服务协议要求终止运营至少提前 60 日在游戏内及服务页面公告并关闭支付，公告持续至正式下线

退服执行清单

  • 法务确认合同通知期、用户公告、退款或虚拟资产处理方案。
  • 研发冻结充值入口和新账号入口，保留必要的查询、退款和客服能力。
  • 发行同步游戏内、详情页、官网和客服渠道公告，并保存发布证明。
  • 财务完成订单、退款、平台账单、发票、达人费用和保证金核对。
  • 数据负责人按隐私政策和法律要求完成数据留存、迁移、删除或匿名化。
  • 下架后继续处理客服、退款、申诉和监管请求，直至合同及用户义务结清。

10. 常见问题（FAQ）

Q1：个人开发者能按本手册入驻吗？

抖音原生手游主流程按游戏平台列出的企业材料执行。快手 Android 联运主体条件以游戏生态合作平台的准入页面和协议为准。小游戏和小玩法不适用本手册。

Q2：同一款原生手游可以同时进入抖音和快手吗？

技术上可以分别适配抖音原生手游和快手 Android 联运，但包体、SDK、账号、支付和结算均独立。是否存在独家、首发期、渠道包或资源限制，以各平台已签协议和书面政策为准。

Q3：抖音后台允许纯广告游戏上传承诺书并填“0”，是否等于不需要版号？

不等于。该操作只表示抖音直播联运后台当前提供的材料提交路径，不构成出版审批豁免。正式提供网络游戏服务前，应由法务和出版单位按产品形态确认审批条件。

Q4：抖音创建游戏时都选官方包吗？

不是。包型取决于合作方案：资料分发、开放 SDK 或发行人计划等使用官方包；普通联运和直播联运使用相应联运包，并分别配置 union_mode=0 或 1。

Q5：审核周期如何排期？

抖音游戏资料现行指南为提交后 3 个工作日内通知结果。快手 Android 联运没有适用于所有项目的公开统一 SLA，应按合作后台和书面排期执行，并为驳回、重新出包和复验预留时间。

Q6：快手手游是否支持 iOS 联运？

本手册核验到的快手联运 SDK 与下载文档为 Android 路径。iOS 是否开放及其接入方式，应以游戏生态合作平台当前能力和书面合作方案为准。
