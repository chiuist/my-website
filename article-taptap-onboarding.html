PLATFORM / TAPTAP

TapTap 新游入驻流程手册

V1 · 国内版 调研数据截至 2026 Q2 TapTap 开发者平台 预约 · 测试 · 公测 含合规资质速查

核心要点：TapTap 平台不抽取渠道流水分成。中国大陆地区无版号游戏可以创建页面和开放预约；免费包体测试须按游戏联网情况完成 APP 备案、防沉迷和隐私合规等要求，且不得包含任何内购或变相计费。预约或纯信息展示阶段仅开放页面，不提供包体下载或正式运营服务。

1. 开发者入驻与认证

1.1 进入开发者中心

使用 TapTap 账号访问 developer.taptap.cn 并进入「开发者中心」。登录后系统自动生成未认证的开发者账号。

1.2 开发者类型与主体认证

开发者类型 所需材料 适用场景
注册开发者 TapTap 账号、厂商名称、已验证的邮箱与手机号等后台要求信息；无需人工审核 仅可使用有限功能并创建创意工坊类游戏；发布常规移动游戏需申请成为认证开发者
认证开发者（个人） 开发者名称、地址、身份证件扫描件、已验证的邮箱和手机号等，以后台要求为准 独立开发者或个人权利主体发布常规游戏
认证开发者（企业） 企业名称、注册地址、统一社会信用代码、营业执照、平台模板认证公函、业务及紧急联系人等，以后台要求为准 公司主体发行、签署授权和提交企业资质

注意：注册开发者可在「开发者中心 → 财务与管理 → 厂商设置 → 成为认证开发者」提交认证申请。企业认证公函须使用平台提供的模板，按后台提示加盖红色公章，并根据年度认证要求及时更新。

1.3 提交认证审核

认证开发者需按后台字段提交审核，并通过站内通知或后台状态查看结果。被驳回时根据具体原因补充或更新材料后重新提交；审核排期以后台展示为准。

完成后状态：认证通过后，即可在开发者中心创建游戏、上传物料、配置页面信息。

2. 创建游戏详情页

2.1 创建游戏项目

在开发者中心点击「创建游戏」，填写以下核心信息：

  • 游戏名称：需与软著登记名称一致（如已有软著），或使用拟定正式名称。名称不可含敏感词、不可与已有游戏重名。
  • 游戏包名（Android）：提交后不可在后台自助修改，需谨慎确认；确需变更时通过开发者中心工单申请，以平台审核结果为准。iOS Bundle ID 按对应平台规则管理。
  • 游戏分类：选择一级和二级分类，影响推荐曝光。
  • 游戏简介：简要介绍核心玩法与特色，建议将主要内容控制在前 50 字，以加深用户第一印象。

2.2 页面物料准备清单

游戏截图 横版 1280×720px 及以上（16:9，宽高比 8:3~8:5），竖版 720×1280px 及以上（9:16，宽高比 3:8~5:8），PNG/JPG；所有截图方向须一致 建议 ≤ 1 MB / 张 至少 3 张 展示核心玩法界面，不含其他平台水印

2.3 合规信息与阶段闸门

创建页面和开放预约阶段仅提供信息展示与预约功能。各阶段应准备并提交以下合规信息：

  • 页面 / 预约：填写真实的游戏名称、主体、联系方式和页面物料；中国大陆地区仅做预约和信息展示时可暂不提交版号，也无需上传 APK。
  • 联网包体测试 / 下载：在提供包体前完成工信部 APP 备案，并准确填写备案编号、主办单位等信息；APP 名称、图标、包名和主体须与备案信息一致。
  • 防沉迷与隐私：提供网络游戏包体测试或下载前，完成实名认证、防沉迷接入及视频证明，并配置可直接访问且内容真实的游戏隐私政策；取得同意前不得初始化会收集个人信息的 SDK。
  • 适龄提示：按平台和主管部门规范标注 8+ / 12+ / 16+，并在游戏显著位置展示。
  • 计费 / 正式上线：按联网、内购等实际形态提交版号、软著或完整授权链、APP 备案、防沉迷和隐私材料；无版号不得开放任何付费、内购或变相计费。

无版号联网测试的特殊路径：申请 TapTap《测试游戏 APP 备案辅助证明》需使用 game.taptap.XXX 专用包名，以「XXX（TapTap测试版）」命名，合作期内 Android 仅在 TapTap 分发，并提交电子协议、承诺、维权授权和软著等材料。申请结果以平台审核为准。

版号提示：如果游戏尚未获得版号，在填写「文号/版号」栏位时可选择「暂无」或留空。但请注意：无版号的游戏不得开放内购计费，预约和免费测试不受此限制。

2.4 提交审核

所有信息填写完毕、物料上传齐全后，点击「提交审核」。首次新建版本预计通常需要 1-3 天，游戏物料和资质审核一般需要 5-7 天。请为补件和复审预留时间，并以后台审核状态为准。

常见驳回原因：ICON 含诱导点击元素、截图包含其他平台水印、游戏名称与软著不一致、隐私政策链接无效或内容为空、分类选择错误。

物料要求 → developer.taptap.cn/docs/store/release/publish/material

3. 开放预约

3.1 预约功能开启

在开发者中心 → 游戏管理 → 选择目标游戏 →「预约设置」中开启预约状态。开启后，TapTap 用户可在游戏详情页点击「预约」按钮。

3.2 预约里程碑奖励

可在开发者中心配置预约里程碑，激励用户传播：

  • 档位数量：最多设置 3 档（如 5 万 / 10 万 / 20 万预约）。
  • 奖励内容：可选游戏内道具、限定皮肤、头像框等虚拟奖励。需明确标注奖励内容和发放方式。
  • 关键规则：里程碑发布后不能自助修改，请谨慎规划；若配置错误或发生不可抗力，应先在社区发布变更公告，再通过开发者中心工单申请处理。

重要限制：预约里程碑发布后原则上锁定，不能在后台自行修改。确需变更时按官方手册先公告说明，再提交工单；是否允许调整以平台审核结果为准。

3.3 预约期运营

运营手段 说明 时效
社区内容运营 在游戏社区板块发布开发日志、角色介绍、世界观文章等 持续进行
开发者的话 游戏详情页展示开发团队给玩家的信，建立情感连接 预约期全程
预约活动 预约抽奖、分享有礼等裂变活动，提升预约转化 测试前 2-4 周高频
预约推送 通过 TapTap 推送通知能力触达已预约用户，通知测试/上线 测试开启前 1-3 天

3.4 预约期合规

预约阶段暂不需要版号，但需保证：

  • 页面展示信息真实准确，不虚假宣传
  • 隐私政策 URL 有效可访问
  • APP 备案号（如有）正确展示
  • 不包含任何内购/付费入口（无版号情况下）

4. 测试阶段

4.1 测试类型总览

测试类型 可见范围 是否需要资格 适用阶段 / 人数上限
内部测试 仅开发者添加的白名单账号 是，白名单制 开发早期，仅限 100 人；需接入 TapTap 登录 SDK
早期玩法测试（篝火测试） 仅首页推荐或站内投放来源用户可参与；无法通过搜索或链接直接访问，非测试用户访问时页面显示 404 是，需领取或获得测试资格；不显示 TapTap 评分 用于早期核心玩法验证，保密性和随机性较强；开启前需接入 TapTap 登录并启用“仅有测试资格可登录游戏”，同时创建封闭式测试计划

开放式测试说明：开放式测试用于正式上线前的 Android 删档测试。正式运营时应根据实际状态选择对应的发布阶段。

不删档测试 测试数据保留至正式服 接近上线状态、需要积累初期用户数据

4.3 计费模式

计费模式 资质要求 说明
免费测试（不计费） 防沉迷 + 防沉迷视频证明 + 隐私政策 + 实名认证 + ICP 备案（联网游戏） 无版号不得计费。普通联网测试仍需完成 APP 备案；申请 TapTap 测试游戏备案辅助证明属于特定独家合作路径，须满足专用包名、命名、授权和协议等条件，并经平台审核
付费测试（计费） 版号（必需）+ 软著（必需）+ 防沉迷 + 防沉迷视频证明 + 实名 + 隐私政策 + ICP 备案（联网游戏） 含内购的测试，版号和软著均必须提供
正式上线（含计费） 版号 + 软著 + 防沉迷 + 防沉迷视频证明 + 实名 + 隐私政策 + ICP 备案 + 适龄提示 以「正式上线」状态运营的完整资质要求（出处：快速入门指南第5章）

⛔ 红线：没有版号的游戏严禁以任何形式开放内购/计费功能，包括但不限于：直接充值、购买道具、订阅服务、通过第三方跳转支付等。违规将导致游戏下架及开发者账号处罚。

4.4 测试包上传与审核

1. 上传测试包

在开发者中心 → 游戏管理 →「版本管理」→ 选择「测试版本」→ 上传 APK（Android）。iOS 封闭/篝火等受限测试可按对应文档填写 TestFlight 链接；Android 包需完成防沉迷接入。

2. 配置测试参数

设置测试类型（内部/封闭/公开）、测试人数上限、测试起止时间、是否需要资格审核、以及是否计费。

3. 提交审核

测试计划、游戏版本及资质分别提交审核。建议至少提前 72 小时准备状态切换；物料和资质审核一般需要 5-7 天。请留足补件时间，并以后台状态为准。

4. 测试期管理

测试期间可通过开发者中心查看下载量、活跃用户数、崩溃率等数据。社区板块收集玩家反馈，及时响应 Bug 报告。

iOS 测试特别说明：iOS 封闭式/篝火等受限测试通过 TestFlight 链接分发，开发者需先在 App Store Connect 配置对应测试。由于 TestFlight 公开链接人数限制，TapTap 当前不支持 iOS 开放式测试；Android 端通过 TapTap 下载 APK。

4.5 测试阶段合规要求

  • 防沉迷：所有测试（含免费测试）必须接入国家统一防沉迷实名认证系统，并提交防沉迷接入视频证明。
  • 隐私政策：游戏内需展示隐私政策入口，且在 TapTap 页面配置有效链接。
  • SDK 合规：接入的第三方 SDK（广告、统计等）需在隐私政策中披露。
  • 计费合规：付费测试必须提供游戏版号 + 软著双证。任何形式的计费（含内购、付费下载、订阅）均需版号和软著。
  • 无版号联网测试：普通项目仍需完成 APP 备案；平台备案辅助证明仅面向满足专用包名、TapTap 独家 Android 分发、协议和权利材料等要求的特定合作项目，须单独申请审核。

5. 正式公测 / 上线

5.1 上线前资质总检查

资质文件清单（全部必备）

  • 国家新闻出版署核发的网络游戏出版物号（版号）
  • 国家版权局核发的计算机软件著作权登记证书（软著）
  • APP 备案编号（工信部 APP 备案系统完成备案；联网游戏分发前必需，且不同于网站 ICP 备案号）
  • 防沉迷系统接入证明（含接入视频证明，国家统一实名认证系统）
  • 隐私政策（游戏内 + TapTap 页面的有效链接）
  • 适龄提示（8+ / 12+ / 16+ 分级标注）

5.2 正式包上传

在版本管理中选择「正式版本」，上传正式 APK（Android）包。需确保：

  • 包名与创建游戏时填写的一致
  • 已接入防沉迷 SDK（如使用 TapTap 防沉迷 SDK 需确认版本最新）
  • 包内不含测试环境配置、调试开关等
  • iOS 侧同步在 App Store Connect 提交审核

5.3 发布操作流程

1. 上传正式包并通过审核

首次新建版本公开指引预计通常为 1-3 天；物料和资质提审一般为 5-7 天。排期应分别预留时间，具体以后台审核状态为准。

2. 配置「正式上线」状态

在游戏管理中将游戏状态切换为「正式上线」。

3. 推送通知激活预约用户

通过 TapTap 推送能力向所有已预约用户发送上线通知，引导下载。

4. 上线后数据监控

关注下载量、活跃、留存、付费等核心指标，及时处理社区反馈和 Bug 报告。

5.4 运营工具

常见问题 FAQ

Q1：没有版号能在 TapTap 上线吗？

可以预约和进行免费测试，但不能开放内购计费，也不能以「正式上线」状态运营。正式运营必须有版号。

Q2：预约里程碑设错了能改吗？

发布后不能自助修改。若配置错误或发生不可抗力，应先发布变更公告，再通过开发者中心工单申请处理；最终以平台审核结果为准。

Q3：iOS 和 Android 可以分别上架吗？

可以分别配置。TapTap 商店 Android 端上传 APK；iOS 受限测试可使用 TestFlight，iOS 正式上线仍需在 App Store Connect 提交审核。当前开放式测试仅支持 Android。

Q4：认证公函过期了怎么办？

需重新下载最新模板、填写并加盖公章后上传。公函有效期为一年，建议在到期前 30 天提前更新，避免影响游戏运营。

Q5：审核被驳回最多的原因是什么？

排名前三：① 游戏名称与软著不一致；② ICON/截图含其他平台水印或诱导性元素；③ 隐私政策链接无效或内容不全。

Q6：TapTap 的分成比例是多少？

TapTap 平台不参与流水分成，游戏收益 100% 归开发者。具体结算安排以开发者后台和有效协议为准。

Q7：测试包和正式包有什么不同？

测试包可选择测试类型、人数限制和资格审核，数据可设定为删档。正式包则面向所有用户开放，数据持久保留。两者在审核要求上也有区别：计费测试和正式包都需要版号+软著。

Q8：可以同时跑多个测试吗？

需按测试类型判断：同一游戏同一时间只能有一个发布中的封闭或开放测试计划；内部测试最多开启一个，但可以与封闭/开放测试并存。结束当前发布计划后可创建新计划，人数不与已结束计划累计。

Q9：防沉迷 SDK 怎么接入？

可使用 TapTap 提供的 TDS 防沉迷 SDK，或自行接入国家新闻出版署统一的实名认证系统。接入后需完成测试验证，确保实名认证和时长限制功能正常工作。

Q10：游戏页面审核和包审核是分开的吗？

是的。页面/版本、物料资质和 APK 包体存在不同审核环节；页面可先用于预约，但提供下载前必须确保包体及该阶段所需资质均已审核通过。

6. TapTap 资源置换与拓展政策

TapTap 平台虽不参与流水分成，但为开发者提供了丰富的资源置换和流量扶持机制。通过为 TapTap 贡献品牌曝光、用户增量和站内活跃度，开发者可换取等值的站内流量和广告资源，实现近乎零成本的获客增长。

6.1 TapTap REP 资源置换平台

TapTap REP（Resource Exchange Platform，资源置换平台）是 TapTap 为游戏厂商打造的官方流量运营平台。厂商只需上传能够为 TapTap 带来正面价值的资源，平台将自动化评估资源价值，发放对应的流量包 / 广告包 / 联合投放包。

1. 上传 TapTap 相关资源

在 REP 后台提交品牌资源、效果资源、运营资源或联合投放素材授权。

2. 平台自动化评估置换

平台根据资源价值、营销效果、用户质量、站内活跃度等多维度评估，生成对应额度的流量/广告金。

3. 使用资源获量增长

使用流量包/广告包创建推荐计划或投放计划，在 TapTap 首页、搜索、信息流等资源位获得展现。

6.6 任务中心与厂商信用扶持

  • 任务中心：包括新手任务、每月任务和合作任务。具体条件及奖励以 REP 后台展示为准；奖励仅限在 REP 平台使用，不能转让或提现。
  • 厂商信用等级：采用 S/A/B/C/D 分级，并与游戏标签分别管理。新入驻或经营时间较短的厂商通常从 C 级起步，等级由产品、运营、口碑和合规记录综合评定。
  • 冷启动扶持：面向已开通 REP 的 S/A 级厂商；首次预约或首次下载可分别获得 30,000 / 10,000 次首页曝光，实际资格以 REP 后台为准。
  • 优质厂商下载里程碑：S/A 级厂商达到 10 万、100 万、500 万下载时，可分别获得 1,000、10,000、20,000 元流量金；奖励在政策有效期内首次达到对应阶梯时发放。
