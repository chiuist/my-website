# ThenDo 1.5

- 与 Mac App Store 首个正式版本对齐版本号，功能与 1.3 相同。
- 官网版可在应用内更新：右键菜单「检查更新…」可查看当前版本并手动检查，启动时及每 6 小时也会自动检查。
- 发现新版本后可在应用内下载、安装并重启；也可以稍后再说或跳过该版本。
- 删除任务前先确认，取消则保留任务。

旧版官网安装包（1.2 及更早）没有内置更新功能，需要手动安装一次本版本；之后就能在应用内更新。

# ThenDo 1.5

- Aligned with the first Mac App Store release; features are the same as 1.3.
- The website edition updates itself: choose Check for Updates… from the menu to see your current version and check manually; ThenDo also checks at launch and every 6 hours.
- When a new version is available, download, install, and relaunch from inside the app, or choose Later or Skip This Version.
- Deleting a task asks for confirmation; cancelling keeps the task.
- The privacy policy explains the network requests used to check for updates.

Older website builds (1.2 and earlier) have no built-in updater, so install this version manually once; after that, updates happen in the app.
