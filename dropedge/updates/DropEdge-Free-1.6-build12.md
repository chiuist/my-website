# DropEdge 1.6

- 新增菜单栏“检查更新”：官网版可在应用内下载、安装并重启，App Store 版会跳转商店更新。
- 有新版本时，菜单会主动显示轻量提醒。
- 优化暂存框动态高度下的连续圆角、快捷操作按钮反馈与整体视觉细节。
- 修复双击打开文件和若干稳定性问题。

---

- Added **Check for Updates** to the menu bar. The website edition can download and install updates in-app; the App Store edition opens the store listing.
- Shows a subtle menu reminder when a new version is available.
- Refined dynamic shelf corners, quick-action feedback, and visual details.
- Fixed double-click file opening and other stability issues.
