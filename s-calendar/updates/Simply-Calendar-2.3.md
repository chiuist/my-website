# 日历即日历 2.3（官网版）

- 菜单栏直接显示今天的日期：默认在日历图标中显示当天日期，也可以在设置中改为“9月27日 周日”“9月27日 八月十七”等文字样式。
- 新增全局快捷键：在任何应用中按 ⌃⌥C 展开或收起日历，可在设置中更换或关闭。
- 法定放假与调休安排改为在线更新：国务院公布新一年安排后，日历会自动更新“休 / 班”，无需升级应用；尚未公布的年份会明确提示。
- 节假日倒计时加入清明节。
- 其他稳定性改进。

官网版不含应用内购买。iCloud 同步、大小周与外观定制属于 PRO，请从 Mac App Store 安装正式版本购买或恢复，已有数据会继续使用。
